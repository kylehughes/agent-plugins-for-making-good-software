## index.md

# Finch help

Finch publishes public-news articles. Each article has one editable draft and a sequence of numbered published editions. A new article has a draft and no published edition.

Saving changes only the draft. Preview shows that saved draft to signed-in editors; it is never the public address. Publish creates a new numbered edition from the saved draft and makes it public at the article's permanent address. An existing public edition stays visible until another is published.

- [Publish an article](publish.md#publish): check the saved draft, publish it, and verify the public result.
- [Preview a draft](publish.md#preview): check saved changes without making them public.
- [Restore an older edition](restore.md#restore): replace the draft with a previous published edition, then publish separately if wanted.

All editors can save and preview. Only editors with Publisher access can Publish or Restore. Finch has no approval workflow; any organizational approval happens outside the tool.

## publish.md

# Publishing

## Publish

Publish creates a new numbered edition from an article's saved draft and makes it public at the permanent address. Saving and Preview alone do not change the public article; an existing public edition stays visible until a new one is published.

You need Publisher access to Publish. Other editors can save and preview. Finch has no approval workflow; handle any required organizational approval outside the tool.

1. Save the draft and wait for Save to complete. Unsaved edits are not included in Preview or a published edition.
2. Open Preview and confirm the article title, date, and body. Preview is visible to signed-in editors and is never the public address.
3. Select Publish.
4. Check the Editions panel. On success, it marks the new numbered edition Current and provides the permanent public address.
5. Open that address in a signed-out browser and check the public result.

If Publish fails, the current public edition stays as it was. Keep the draft and contact the help desk with the article ID and error text. If the result is unclear, check Current in the Editions panel before doing anything else. Do not repeatedly Publish to try to fix it.

To bring back an older edition, [restore it into the draft](restore.md#restore) first, then follow these publishing steps.

## Preview

Preview shows an article's saved draft to signed-in editors. Save and wait for completion before opening Preview; unsaved edits are not included. Check the title, date, and body there.

Preview never shows the public address and does not publish changes. To make the draft public, follow [Publish](#publish); that requires Publisher access. After publishing, use the permanent public address in Editions and a signed-out browser to check what the public sees.

## restore.md

# Older editions

## Restore

Restore copies an older published edition into the article's editable draft. It does not change the public article or create a new edition. Use it only for an article with published editions; a new article has none to restore.

You need Publisher access to Restore, even though other editors can edit drafts.

> [!WARNING]
> Restore replaces the current draft. There is no draft history or undo for Restore. Before restoring, save a copy of the draft text outside Finch if you need to keep it.

1. Verify the article ID and the selected edition number in the Editions panel.
2. Select Restore for that edition.
3. Open Preview and check the restored draft, including its title, date, and body. Preview is for signed-in editors; it is never the public address.
4. If you want the restored draft to become public, follow [Publish](publish.md#publish), including saving first and checking the public result. Until you publish, the existing public edition remains visible.
