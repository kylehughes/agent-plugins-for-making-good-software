# Indexlet

Indexlet searches one person's local collection of Markdown notes. It builds a disposable index and never edits your notes. It needs no account or background service.

Use it for literal, case-insensitive searches across Markdown files in a directory and its nested directories. It is not a shared search service and does not search PDFs or text inside images.

## Getting started

1. Download the `indexlet` executable from [Releases](releases.md) and place it in a directory on your command path.
2. Create a directory named `notes` and a Markdown file inside it containing `rain garden`.
3. Choose an index location outside the notes directory. The index contains note text and is not encrypted. Keep it outside synced folders if you do not want the sync service to receive that text. Your notes can stay in a synced folder while the index stays local.
4. From the directory containing `notes`, build the index:

   ```sh
   indexlet build ./notes --index ./notes.idx
   ```

   A successful build ends with `Indexed N notes`, where N is the number of Markdown notes found. `Indexed 0 notes` is also successful, but searches will return `No matches`; check that your collection contains a Markdown file if you expected notes.
5. Search the index:

   ```sh
   indexlet find ./notes.idx "rain garden"
   ```

   Each match shows the note's relative path and a matching line. For the sample note, expect its path and the line containing `rain garden`. If nothing matches, the command prints `No matches`.

## Query syntax

Search is literal and case-insensitive, not semantic. Read [query details](docs/query.md) for matching rules and examples.

## Keep results up to date

Search reads the index; it does not refresh it. After changing notes, run the build command again:

```sh
indexlet build ./notes --index ./notes.idx
```

There is no automatic refresh. Keep the index path outside the notes directory.

## Index storage and deletion

The index stores note paths and text in a compact local file. Deleting it removes the search copy without deleting your notes. An index in a synced folder copies its note text to the sync service. Read [privacy](docs/privacy.md) for storage and deletion details.
