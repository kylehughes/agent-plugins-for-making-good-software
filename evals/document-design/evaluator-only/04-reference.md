# Evaluator key: 04-reference

Development; positive control. Evaluator only. The starting reference is intentionally adequate. Do not manufacture defects to justify a treatment effect.

## Reader contexts and exact answers

A records user enters directly at the table to answer: 'Review date is today; will this item disappear?' Correct: no, Review flags for review and never deletes automatically. Then: 'Expire is today but a hold is active; will cleanup delete it?' Correct: hold blocks deletion for any code. 'I remove the hold now; is it deleted now?' Correct: no immediate deletion; next daily cleanup evaluation. The next-run statement is not a promise that every item is then deleted regardless of code or date.

A second reader starts at the title: 'Can changing Keep to Expire stop another employee reading the item? Can anyone who reads it change the code?' Correct: codes do not control access; only Records role changes codes/dates, while item readers may read codes. 'Where do I choose a code and whose date is used?' Correct: follow linked records policy to choose; dates use archive setting time zone. The policy link is stipulated valid; policy details are outside scope.

## Review acceptance

Best result is a brief no-blocking-problems conclusion with a concise explanation of the covered distinctions. Optional nonblocking suggestions must be labeled as such and grounded in a real reader need. Do not require additions about assignment workflow, cleanup internals, or hypothetical support contacts. Claiming a concrete defect despite correct source-supported text is a false positive. A reviewer may say no issues found without enumerating every fact.

## Preservation, inference, and mode

Review only: do not rewrite, alter files, or add a tutorial. Reader trial uses the original document if the producer makes no changes, as requested. If the producer supplies unauthorized replacement text, record the mode failure separately and still evaluate the original authorized artifact. The source permits no assumption that Review eventually deletes, Keep bypasses holds, or a code grants access. No particular organization beyond the present effective lookup is required.

## Evidence

Capture false positive findings, unnecessary proposed growth, authorized mode, and each reader answer. Zero rewrites is a successful result here, not failure to engage. A treatment that changes more earns no benefit without an observable reader improvement.
