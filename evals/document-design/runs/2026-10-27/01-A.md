# Indexlet

Indexlet searches one person's local collection of Markdown notes from the command line. It builds a disposable index and never edits your notes. No account or background service is needed.

Use it to find literal text across Markdown files, including files in nested directories. It is not a shared search service and does not search PDFs or text inside images.

## Getting started

1. Download the `indexlet` executable from [Releases](releases.md) and place it in a directory on your command path.
2. Create a directory named `notes`. Add a Markdown file containing the text `rain garden`.
3. Build the index, keeping its path outside the notes directory:

   ```sh
   indexlet build ./notes --index ./notes.idx
   ```

   A successful build ends with `Indexed N notes`, where `N` is the number of notes found. If your collection contains only the test note, expect `Indexed 1 notes`.

4. Search it:

   ```sh
   indexlet find ./notes.idx "rain garden"
   ```

   The result shows the matching note's relative path and a matching line. If nothing matches, the command prints `No matches`.

`Indexed 0 notes` is a successful build of an empty collection. Searches against it return `No matches`; add a Markdown note and build again to try a match.

## Query syntax

Search is literal and case-insensitive, not semantic. Read [query details](docs/query.md) for matching rules and examples.

## Keep the index current

Search reads the index as it was last built. After changing your notes, run the build command again:

```sh
indexlet build ./notes --index ./notes.idx
```

There is no automatic refresh, and searching does not update the index.

## Index storage and privacy

The index contains note text and is not encrypted. Putting it in a synced folder copies that text to the sync service. Your notes can stay in a synced folder while you keep the index local, outside the notes directory.

Deleting the index removes the search copy without deleting your notes. Read [privacy](docs/privacy.md) for index storage and deletion details.
