## index.md

# Finch help

Finch publishes public news articles. Each article has one editable draft and, after its first publication, numbered published editions. A new article has a draft and no published edition.

Saving changes only the draft. Preview shows the saved draft to signed-in editors. Publish creates a numbered edition and makes it public at the article's permanent address; an existing public edition stays visible until another is published.

- [Publish an article](publish.md#publish): check the saved draft, publish it, and verify the public result.
- [Preview a draft](publish.md#preview): check changes before publishing.
- [Restore an older edition](restore.md#restore): replace the draft with an older edition, then publish it if needed.

All editors can save and preview. Publish and Restore require Publisher access. Finch has no approval workflow; complete any required organizational approval outside Finch.

## publish.md

# Publishing

## Publish

Publish creates a new numbered edition from the saved draft and makes it public at the article's permanent address. Saving alone does not publish anything. For an article that is already public, the current edition stays visible until a new one is published.

You need Publisher access to Publish. Other editors can save and preview. Complete any required organizational approval outside Finch; the tool has no approval workflow.

1. Save the draft and wait for Save to complete. Unsaved edits are not included in Preview or a published edition.
2. Open Preview and confirm the title, date, and body.
3. Select Publish.
4. In the Editions panel, confirm that the new edition is marked Current. The panel provides the article's permanent public address.
5. Open that address in a signed-out browser and check the public result.

If Publish fails, the current public edition stays as it was. Keep the draft and contact the help desk with the article ID and error text. If the result is unclear, check Current in the Editions panel before taking further action. Do not repeatedly select Publish to resolve uncertainty.

To use an older edition as your draft, see [Restore](restore.md#restore).

## Preview

Preview shows the saved draft to signed-in editors. It is never the public address, and it does not change the public article.

Save and wait for completion before opening Preview. Check the title, date, and body, then follow the [publishing steps](#publish) when the draft is ready to go public.

## restore.md

# Older editions

## Restore

Restore copies a selected older published edition into the article's editable draft. It does not change the public article or create a published edition. You need Publisher access to Restore, even though other editors can edit drafts. A new article with no published editions cannot be restored.

> [!WARNING]
> Restore replaces the current draft. There is no draft history or undo for Restore. Save a copy of the draft text outside Finch first if you need to keep it.

1. Verify the article ID.
2. In the Editions panel, select the older edition and verify its edition number.
3. Select Restore.
4. Open Preview and check the restored draft's title, date, and body. Preview is visible only to signed-in editors; it is never the public address.

The existing public edition remains visible. If you only need to restore the draft, stop here.

To make the restored draft public, complete any required organizational approval outside Finch, then:

1. Save and wait for completion. Unsaved edits are not included in Preview or a published edition.
2. Open Preview and confirm the title, date, and body.
3. Select Publish. This requires Publisher access and creates a new numbered edition from the saved draft.
4. Confirm that the Editions panel marks the new edition Current.
5. Open the permanent public address provided by that panel in a signed-out browser and check the result.

If Publish fails, the current public edition stays as it was. Keep the draft and contact the help desk with the article ID and error text. If the result is unclear, check Current first; do not repeatedly select Publish.

See [Publishing](publish.md#publish) for the publishing procedure or return to [Finch help](index.md).
